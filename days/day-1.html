--- Day -1: Grinch! ---

By Alston Liu

Welcome to day negative one! Somehow this is achievable with time travel. The engineer who automated the Christmas tree decorations has time-traveled to Las Vegas, leaving the Grinch a chance to scramble the lights.

Decorations of the same color now appear next to each other. Find how many neighboring decorations need your attention so the tree can shine again.

--- The decoration list ---

Your input contains rows of digits. Each digit is a color. Choose one digit from each row:

  1. From the first row, choose the first digit; from the second, choose the second; and so on.
  2. If that position goes past the end of a row, wrap around to the beginning of the same row as many times as needed.
  3. Compare each chosen digit with the one chosen from the previous row. Count one match when they are equal. The first row has no previous row and contributes no match.
123456
0123456
654321
123

The chosen digits are 1, 1, 4, 1. On row four, position four wraps to position one. Only the first pair matches, so the example answer is 1.

How many adjacent pairs of chosen digits match in your input?
