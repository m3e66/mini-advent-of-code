--- Day 2050: Time Travel!? ---

By Leo Xu

Merry Christmas! Santa is throwing a party for time travelers. A strong magnetic field at the North Pole makes your time machine flicker forward after each visit. Find the starting hour that gives you the most visits with Santa before the party closes.

--- Find the eligible hours ---

First generate terms a[0] through a[744] of the following sequence. Start with a[0] = 0. At step n, try subtracting n from the previous term. Use that result if it is nonnegative and has never appeared before. Otherwise add n to the previous term; addition may repeat a number.

n = 1: 0 - 1 is negative; use 0 + 1 = 1
n = 2: 1 - 2 is negative; use 1 + 2 = 3
n = 3: 3 - 3 = 0 was already used; use 3 + 3 = 6
n = 4: 6 - 4 = 2 is new; use 2

First terms: 0, 1, 3, 6, 2, 7, 13, 20, 12, 21, ...

A starting hour is eligible if it appears anywhere in those 745 terms. Your input is an inclusive range start-end. Only consider eligible starting hours in that range.

--- Take the forward jumps ---

For each candidate starting hour h, count the starting visit. Your first forward jump has size h, except that hour 0 starts with a jump of size 1. Increase the jump size by 1 after every jump. Stop before a jump would land after hour 744. Landing exactly on hour 744 counts. Later landings do not need to be eligible sequence terms.

The sequence determines which starting hours are allowed; the forward-jump rule determines the visits.

Example with a closing hour of 10 and input 1-3:
Start 1: 1, 2, 4, 7       = 4 visits
Start 2: 2, 4, 7          = 3 visits
Start 3: 3, 6, 10         = 3 visits
Answer: 1

Your real closing hour is 744. If several candidates give the same number of visits, choose the smallest starting hour. If no starting hour is eligible, answer -1.

Which starting hour in your range gives the most visits?
